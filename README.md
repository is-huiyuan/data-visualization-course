# 数据可视化课程网站

面向管理类本科生的轻量课程学习网站。内容包括知识脉络、10章学习笔记、章节练习与测验、4次实验、图表选择演示，以及可下载的原创Notebook和教学模拟数据。

## 本地浏览

直接用浏览器打开本目录的 `index.html` 即可，无需安装软件或联网。也可以在本目录启动任意静态文件服务，例如：

```bash
python3 -m http.server 8000
```

再在浏览器打开 `http://localhost:8000`。

## 内容维护

- `data/course.js`：课程简介、章节、练习、测验、实验和术语。
- `app.js`：页面、搜索、学习进度、测验和图表演示。
- `styles.css`：桌面与手机样式。
- `resources/`：原创练习Notebook、教学模拟数据和整包下载。

修改 `data/course.js` 后，使用Node.js运行 `node scripts/build.mjs` 更新浏览器可直接读取的 `data/course-data.js`。这是内容生成步骤，网站本身没有运行依赖。

学习进度仅保存在浏览者当前设备的本地存储中。网站无需账号，未接入服务端学习数据库或第三方统计脚本，也没有个人信息提交表单。

## GitHub Pages

这是一套无需构建步骤的静态网站，兼容GitHub Pages的项目子路径。发布时可将本目录作为新仓库根目录，在仓库 **Settings → Pages** 选择 **Deploy from a branch**，分支 `main`，目录 `/(root)`。

当前版本只在本地准备，尚未创建远程仓库或发布。

## 资源范围

网站正文为依据课程主题编写的学习摘要与练习，不包含教师私人联系方式、学生作业、成绩、原始课程附件或校园内网入口。练习数据均为教学模拟，不能作为真实业务证据。原始课程目录不属于此仓库。
